# Authentification administrateur

## À quoi sert cette interface ?

Cette interface permet de créer un compte administrateur, de se connecter et de se déconnecter.

---

## Qui peut créer un compte administrateur ?

Toute personne disposant du code de sécurité demandé lors de l'inscription.

---

## Pourquoi un code de sécurité est-il demandé ?

Le formulaire vérifie un code de sécurité avant d'autoriser l'inscription ou la connexion.

---

## Quelles informations sont nécessaires pour créer un compte ?

Le formulaire demande :

- une adresse email ;
- un mot de passe ;
- un code de sécurité.

---

## Quelles informations sont nécessaires pour se connecter ?

Le formulaire demande :

- une adresse email ;
- un mot de passe ;
- un code de sécurité.

---

## Puis-je afficher mon mot de passe ?

Oui.

Un bouton permet d'afficher ou de masquer le mot de passe pendant la saisie.

---

## Que se passe-t-il si le code de sécurité est incorrect ?

L'opération est interrompue et un message d'erreur est affiché.

---

## Que se passe-t-il si une erreur survient ?

Le formulaire affiche un message correspondant au problème rencontré.

---

## Que se passe-t-il après une connexion réussie ?

L'utilisateur est redirigé vers la page des statistiques.

---

## Comment se déconnecter ?

La déconnexion supprime la session en cours puis redirige automatiquement vers la page d'inscription administrateur.
